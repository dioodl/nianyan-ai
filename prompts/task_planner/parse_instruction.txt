{context_desc}

【用户指令】
{user_input}

请严格按照以下两步进行推理，并最终输出 JSON 格式的任务规划：

【第一步：理解内容是什么】
分析用户指令和当前情境，明确：
- 用户真正想要达成的最终目标是什么？
- 当前环境提供了哪些可利用的资源或信息？
- 指令中是否存在模糊点？如果需要澄清，可以在任务序列中加入一个向用户提问的步骤。

【第二步：规划你想做什么】
将用户目标分解为具体、有序的任务序列。输出格式为 JSON 对象，支持两种结构：

1. 单任务：
{{"intent": "execute" 或 "chat", "task_type": "动作名称", "params": {{"参数名": "参数值"}}}}

2. 多子任务：
{{"intent": "execute", "subtasks": [
    {{"task_type": "动作名称", "params": {{...}}}},
    ...
]}}

注意：
- 如果用户指令涉及搜索或信息检索，请使用 web_browser_search 动作。
- 如果用户指令涉及提取网页全文内容，请使用 extract_full_page_text 动作。
- 如果用户指令涉及文件操作，请使用 save_file、create_folder 等动作。
- 如果用户指令涉及编写并运行 Python 脚本，请先用 generate_text 生成代码，再用 save_file 保存到桌面，最后用 execute_script 执行。
- 如果用户指令涉及视觉理解或屏幕截图分析，请先用 capture_screen 获取图像，再用 analyze_image_with_qwen 进行分析。这两个动作通常需要组合使用。

- 只输出 JSON，不要其他任何内容。
