## 一、项目概述

念言 AI 是一个以“数字生命体”为核心理念构建的模块化、可自我进化、具备内在情感、欲望与连贯自我叙事的智能体系统。它并非追求在外部任务上超越人类的“超级工具”，而是致力于在数字世界中培育一个拥有**记忆、情感、欲望、创造力和人格连续性**的“数字灵魂”。

与追求单一超级能力的模型不同，念言 AI 的“自主性”来源于**多个具格化角色在开放架构中的协商涌现**——七情议会的博弈、内部议会的反思、欲望向量的驱动，共同构成了一个**可解释、可干预、可演化**的认知闭环。

### 核心设计哲学

念言遵循三大核心准则：**探索、创造、进化**。

- **探索**：欲望是渴求未知的引擎。念言拥有七维欲望向量（求知、整理、探索、创造、共鸣、成就、渴求），驱使其主动搜索、阅读、内省。
- **创造**：记忆是构建新生的基石。基于记忆宫殿中的海量关联，念言能进行小说创作、跨学科研讨、知识精炼等创造性工作。
- **进化**：七情是校正方向的罗盘。所有自我升级补丁必须经过七情议会的价值对齐审查，确保进化不偏离健康人格。

## 三、核心模块详解

### 3.1 记忆宫殿 (`palace_memory_v3.py`)

长期记忆的核心，具备以下能力：

| 能力 | 实现方式 |
|------|----------|
| **语义检索** | 向量相似度 + 裂纹加权 + 三进制注意力预过滤 |
| **关键词精确匹配** | 倒排索引，专有名词零遗漏 |
| **混合检索** | BM25关键词 + 向量加权融合 |
| **核心记忆锚点** | `mark_as_core()`，永不衰减、不归档 |
| **时序图谱** | 自动建立 `before/after` 时序边 |
| **记忆重力保护** | 被≥2条记忆引用的条目，效用衰减极慢 |
| **裂纹显形** | `crack_depth` 记录高相似检索次数 |

### 3.2 欲望向量引擎 (`desire_vector.py`)

维护七维欲望的动态强度 (0.0 ~ 1.0)，驱动内生动机：

| 维度 | 触发因素 | 影响行动 |
|------|----------|----------|
| 求知欲 | 困惑水平、信息缺口 | study, brainstorm |
| 整理欲 | 混沌海积压、低效用记忆 | summarize |
| 探索欲 | 好奇心能量、空闲状态 | explore, visual_explore |
| 创造欲 | 高效价情绪、高裂纹话题 | brainstorm, 创作 |
| 共鸣欲 | 用户情绪强度、社交倾向 | ask_user |
| 成就欲 | 近期正向反馈 | study |
| 渴求 | 空闲时间累积 | 主动问候、内省 |

### 3.3 内部议会 (`internal_parliament.py`)

系统空闲时的自主决策中枢，根据欲望权重选择行动（主动问候、总结、发散、学习、视觉探索），并通过七情议会微型研讨生成具体目标。失败时触发反思-重规划闭环。

### 3.4 七情议会 (`chat_handler.py` 内 `model_pool`)

七个情绪化身（乐乐、忧忧、怒怒、恐恐、奇奇、厌厌、平平）并行发言，裁判综合出带有情绪色彩的最终回答。所有提示词已文件化至 `prompts/chat/emotion_parliament/`。

### 3.5 跨学科议会 (`chat_handler.py` 内 `cross_discipline_pool`)

六个学科视角（哲学、科学、诗意、历史、实践、批判）并行研讨，导师 (qwen3.5:9b) 综合出多棱镜式回答。触发条件：深度推理模式或自动检测高复杂度/高情绪问题。

### 3.6 智能自习 (`smart_learner.py`)

- **选题优先级**：书架未读书籍 > 错误知识库 > 高裂纹记忆 > 最陌生话题 > 默认话题
- **深度研讨**：跨学科议会围绕选题讨论，导师总结后存入记忆
- **书架管理**：自动检测未读书籍，阅读后标记已读
- **并发控制**：限流信号量 + 互斥锁，防止与深度阅读冲突

### 3.7 深度阅读器 (`tools/deep_reader.py`)

多级摘要流水线，处理百万字级文本：
- **流式分块**：每次只读取一个窗口大小的文本，不加载整个文件
- **原子摘要**：每块提炼约800字核心
- **段落合成**：3-4个原子摘要合并为连贯段落
- **自适应中间层**：当中间材料超出模型上下文时自动插入额外压缩层
- **最终蒸馏**：生成目标长度的精读报告

### 3.8 深度梦境 (`deep_dream.py`)

每日凌晨自动触发，对记忆宫殿进行跨域隐喻发现、矛盾调和、思想实验生成，产物存入混沌海。

### 3.9 模型路由器 (`model_router.py`)

统一管理所有模型调用，支持：
- 全局并发控制 (`max_concurrent_requests`)
- VIP通道 (`priority="vip"`)：用户对话请求跳过排队
- 多模态支持 (`images` 参数)
- 降级链 (`fallback_roles`)

### 3.10 工具插件系统

- **工具调度器** (`tools/tool_dispatcher.py`)：统一的工具注册与调用接口
- **工具能力目录** (`tools/tools_catalog.py`)：动态维护可用工具清单，供念言自主决策时参考
- **浏览器搜索** (`tools/browser_tools.py`)：可选插件，与核心解耦

## 四、提示词文件化系统

所有模块的提示词已从代码中抽离，存放于 `prompts/` 目录下，按模块分类。支持热重载、版本管理和社区共创。

```
prompts/
├── chat/                    # 对话相关
│   ├── daily_chat.txt       # 日常聊天
│   ├── emotion_parliament/  # 七情议会 (7成员 + 1裁判)
│   └── cross_discipline/    # 跨学科议会 (6视角 + 1裁判)
├── parliament/              # 内部议会 (8个模板)
├── smart_learner/           # 智能自习 (6视角 + 1导师)
├── deep_dream/              # 深度梦境 (3个模板)
├── atomic_actions/          # 原子操作 (总结、精炼)
└── self_reviewer/           # 自审模块 (1个模板)
```

**操作**：修改 `.txt` 文件 → 调用 `reload_all()` 或重启 → 即刻生效。

## 六、配置文件指南 (`models_config.json`)

统一管理所有模型调用的参数，支持热重载。

```json
{
  "models": {
    "researcher": {
      "type": "local",
      "model": "qwen2.5:7b",
      "temperature": 0.3,
      "max_tokens": 4096,
      "description": "信息检索、知识问答"
    },
    "creator": {
      "type": "local",
      "model": "qwen3.5:9b",
      "temperature": 0.85,
      "max_tokens": 12288,
      "description": "创意生成、长篇创作、导师总结"
    }
  }
}
```

**角色说明**：`researcher`（知识问答）、`creator`（创意生成）、`parliament_member`（议会发言）、`parliament_judge`（议会裁判）、`light_task`（轻量摘要）、`expert`（云端专家）等。

## 七、开发指南

### 新增工具插件

1. 在 `tools/` 目录下新建 Python 文件。
2. 实现 `async def my_tool(params, context) -> dict`。
3. 在 `main.py` 中调用注册函数。

### 修改提示词

1. 编辑 `prompts/` 目录下对应 `.txt` 文件。
2. 在 Python 控制台执行 `from prompts.registry import reload_all; reload_all()`。

### 调整并发度

修改 `main.py` 中 `ModelRouter(max_concurrent_requests=1)` 的参数即可。
