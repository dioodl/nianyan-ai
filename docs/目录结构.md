## 🔑 核心模块说明

| 模块 | 文件 | 功能简述 |
|------|------|----------|
| **入口调度** | `main.py` / `message_bus.py` | 初始化所有模块，全局通信枢纽 |
| **记忆系统** | `palace_memory_v3.py` | 混合检索、时序图谱、重力保护、混沌海 |
| **情感系统** | `emotion_*.py` | 七情议会、情绪累积、情绪注入 |
| **欲望驱动** | `desire_vector.py` / `cognitive_engine.py` | 六维欲望动态、好奇心/困惑/痛苦 |
| **自主执行** | `autonomous_executor.py` / `task_queue.py` | 目标→任务→执行闭环 |
| **自我进化** | `internal_monitor.py` / `code_generator.py` | 红区监测、代码自改进 |
| **专业创作** | `creation_manager.py` / `consistency_auditor.py` | 伏笔检测、一致性审计、因果图谱 |
| **主动学习** | `smart_learner.py` / `auto_learner.py` | 好奇心驱动选题、学生-教师-裁判协同 |

## 📁 数据目录优先级

| 优先级 | 目录 | 说明 |
|--------|------|------|
| 🔴 高 | `memory_palace/` | 记忆文件，丢失即遗忘所有历史 |
| 🔴 高 | `创作/` | 小说、设定、伏笔，创作核心资产 |
| 🟡 中 | `conversation_archives/` | 对话归档，用于后期回溯与学习 |
| 🟡 中 | `desire_state.json` / `permission_state.json` | 欲望状态与权限规则 |
| 🟢 低 | `consistency_reports/` / `causality_graphs/` | 可重新生成的分析报告 |

## 🔧 开发建议

- **添加新模块**：在根目录创建 `.py` 文件，通过 `message_bus.py` 订阅/发布事件即可解耦接入。
- **修改记忆存储**：不建议直接操作 `memory_palace/` 下的 JSON 文件，应通过 `palace_memory_v3.py` 的公开 API。
- **提示词调优**：所有系统提示词在 `prompts/` 目录下，修改后无需重启即可生效（热加载）。
- **配置变更**：修改 `config.py` 后需重启程序。
