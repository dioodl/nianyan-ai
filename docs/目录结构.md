## 三、核心模块功能速查

| 模块 | 文件 | 一句话职责 |
|------|------|-----------|
| 消息总线 | `message_bus.py` | 发布/订阅，全局通信 |
| 对话处理 | `chat_handler.py` | 七情议会、跨学科议会、日常聊天 |
| 任务执行 | `task_executor.py` | LLM意图理解 + 智能分发 |
| 任务规划 | `task_planner.py` | 自然语言 → 原子任务序列 |
| 记忆宫殿 | `palace_memory_v3.py` | 混合检索、时序图谱、核心锚点 |
| 欲望向量 | `desire_vector.py` | 七维欲望动态调节 |
| 内部议会 | `internal_parliament.py` | 空闲自主决策 |
| 智能自习 | `smart_learner.py` | 书架优先 + 跨学科深度研讨 |
| 深度阅读 | `tools/deep_reader.py` | 多级摘要流水线 |
| 模型路由 | `model_router.py` | 统一调用 + 并发控制 + VIP通道 |
| 工具调度 | `tools/tool_dispatcher.py` | 统一注册与调用外部工具 |
| 工具目录 | `tools/tools_catalog.py` | 动态维护念言的“能力认知” |
| 自我叙事 | `self_narrator.py` | 每日生成心智报告 |
| 深度梦境 | `deep_dream.py` | 夜间记忆发现 |
| 自我监控 | `internal_monitor.py` | 红区检测 + 进化触发 |
| 代码生成 | `code_generator.py` | A智脑自动升级 |

```
